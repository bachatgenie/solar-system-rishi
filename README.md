# 🚀 Rishi's Solar System Adventure

A fun, interactive Solar System web app built especially for **Rishi** to learn about planets!

## 🌟 Features

- **Personalized Greeting** — "Hey Rishi! 👋"
- **Interactive Solar System** — Click any planet to learn fun facts
- **Animated Planets** — Watch planets orbit the Sun
- **Planet Information Cards** — Fun facts about each planet
- **Quiz Game** — Test your knowledge and win a surprise!

## 🎯 The Challenge

Take the quiz and score **more than 80%** to win a special prize from **Avadhut Uncle**! 🍫

## 🪐 Planets to Explore

1. ☀️ **Sun** — Our star
2. ☿️ **Mercury** — The Swift Planet
3. ♀️ **Venus** — The Morning Star
4. 🌍 **Earth** — The Blue Planet (our home!)
5. 🔴 **Mars** — The Red Planet
6. 🪐 **Jupiter** — The Gas Giant
7. 🪐 **Saturn** — The Ringed Planet
8. ♅ **Uranus** — The Ice Giant
9. ♆ **Neptune** — The Windy Planet

## 🎮 How to Play

1. **Explore** — Click on planets to read fun facts
2. **Animate** — Click "Start Planets Moving" to see them orbit
3. **Quiz** — Click "Start Quiz!" to test your knowledge
4. **Win** — Score 80%+ to see your surprise message!

## 🛠️ Built With

- HTML5
- CSS3 (animations & gradients)
- JavaScript (no libraries!)
